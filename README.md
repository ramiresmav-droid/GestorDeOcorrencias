# Pendentes Android — versão 1.2

Projeto Android Java, com SQLite local.

## Alterações
- Lista compacta: título, morada e prioridade por linha.
- Toque numa linha para abrir detalhes, fotografia, mapa, edição e concluir/reabrir.
- Campo independente para filtrar por localização/morada, em conjunto com pesquisa por título e filtro de prioridade.
- Mantida a base de dados SQLite e o seu esquema para conservar os registos existentes numa atualização da mesma aplicação.

## Compilar
Abrir esta pasta no Android Studio, sincronizar Gradle e selecionar Build > Build APK(s). SDK 35.

Não foi compilado nem testado num dispositivo neste ambiente.
